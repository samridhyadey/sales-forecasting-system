# Sales Forecasting System (End-to-End)

## Objective
Forecast next 8 weeks of sales using time series models and deploy via REST API.

## Models Used
- ARIMA / SARIMA
- Facebook Prophet
- XGBoost
- LSTM

## Features
- Lag features (t-1, t-7, t-30)
- Rolling mean & std
- Time-based features

## API
GET /predict

## Tech Stack
Python, FastAPI, Pandas, Scikit-learn
